    RA6 - Estructuras Avanzadas de Datos

    ¿Qué aprenderás?

    • Estructuras ArrayList y HashMap - Uso de los métodos típicos para trabajar con estas estructuras
    • Métodos hashCode y equals - Modificar estos métodos de la clase Map

    Nota: Tanto ArrayList como HashMap se incluyeron en la especificación 1.2 de Java y son fundamentales en programación moderna.

    Características importantes:

    • Estas estructuras no pueden trabajar con tipos de datos simples. Debemos usar sus Wrappers (objetos), en un proceso conocido como Boxing
    • Normalmente los métodos hashCode() y equals() se sobrescriben compartiendo criterios para comparar objetos

    Colecciones

    Una colección almacena un conjunto de objetos, es decir, sería como un Array de objetos, pero dinámico. Al ser dinámico, no tienen un tamaño fijo y permiten añadir, eliminar y modificar los elementos durante la ejecución.

    Java, mediante java.util, nos brinda un amplio conjunto de clases para la creación y tratamiento de colecciones.

    Operaciones básicas sobre una colección:

    • Añadir objetos a la colección
    • Eliminar objetos de la colección
    • Obtener un objeto de la colección
    • Localizar un objeto en la colección
    • Iterar a través de una colección

    ArrayList

    Un ArrayList representa una colección basada en índices, al igual que un Array, cada elemento ocupa una posición única. Para acceder a cada elemento tenemos que utilizar un índice.

    Juan (0) | 31 (1) | d (2) | 5.5 (3)

    Declaración

    // Creación de un listado vacío. Al no indicarle el tipo de objetos a incluir,
// este listado puede contener cualquier tipo de objetos.
ArrayList contactos = new ArrayList();
miLista.add("Juan");
miLista.add(31);
miLista.add('d');
miLista.add(5.5);

    Método add(): Añade un elemento al final de la lista.

    ArrayList Tipado

    Un listado compuesto por elementos de diferentes tipos puede provocar errores y es tedioso de manejar. La opción más recomendable es utilizar un tipado para los ArrayList<Object>, de esta forma tendremos un listado de objetos.

    // Creación de un listado de String.
ArrayList<String> contactos = new ArrayList<String>();
miLista.add("Juan");
miLista.add("Rosa");
miLista.add("Pedro");
miLista.add("Ana");
    Juan (0) | Rosa (1) | Pedro (2) | Ana (3)

    Recorrer un ArrayList

    Existen diferentes formas de recorrer un ArrayList:

    Método 1: Usando Iterator

    ArrayList<Integer> list = new ArrayList<Integer>();
Iterator it = list.iterator();
while (it.hasNext()) {
    System.out.println(it.next().toString());
}

    Método 2: Usando for-each

    for (Integer item : list) {
    System.out.println(item);
}

    Método 3: Usando for tradicional

    for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

    HashMap

    • HashMap es una implementación de la interfaz Map de Java. Es una colección de objetos
    • Permite almacenar pares clave/valor, de tal manera que una clave sólo puede tener un valor (las claves no se repiten)
    • No se admiten valores nulos
    • Se utiliza un algoritmo que, a partir de la clave, genera otra clave "hash", que determina el orden en que se almacenarán en memoria
    • Librería utilizada: java.util.HashMap
    Clave 1 | Clave 2 | Clave 3 | Clave 4
    Valor 1 | Valor 2 | Valor 3 | Valor 4

    Declaración

    // Declaración de un HashMap en que las claves serán de tipo String
// y los valores de tipo Integer.
HashMap<String, Integer> map = new HashMap<String, Integer>();

// Añadir elementos en el HashMap
map.put("Pedro", 12345);
map.put("Luis", 54321);

    Importante: Como pasa con los ArrayList, en los HashMap no se pueden usar tipos primitivos (int), se debe utilizar su clase contenedora (Integer).

    Recorrer un HashMap

    Para recorrer un HashMap utilizaremos la interfaz iterator():

    Iterator it = map.keySet().iterator();
while(it.hasNext()){
    String key = (String) it.next();
    System.out.println("Clave: " + key + " -> Valor: " + map.get(key));
}

    Métodos para iterar:

    • keySet() - Devuelve los elementos del HashMap
    • Iterator() - Itera sobre cada elemento
    • hasNext() - Retorna false si no hay más elementos, true si existe un elemento en la siguiente posición
    • next() - Devuelve el siguiente elemento
    • get(key) - Obtiene el valor a partir de la clave dada

    Métodos de HashMap

    Método Descripción
    clear() Vacía el HashMap
    containsKey(key) Indica si el HashMap contiene un elemento con la clave key
    containsValue(value) Indica si el HashMap contiene un elemento con el valor value
    entrySet() Devuelve una copia del HashMap en forma de colección
    get(key) Devuelve el valor asociado a la clave key, o nulo si no existe la clave
    isEmpty() Indica si el HashMap está vacío
    keySet() Devuelve una colección con las claves del HashMap
    put(key, value) Añade un elemento al HashMap. Si existe una clave key, sustituye su valor
    putAll(map) Copia todos los elementos de map en el HashMap que invoca el método
    remove(key) Elimina el elemento con clave key del HashMap si existe
    size() Devuelve un número entero que es el número de elementos que tiene el HashMap
    values() Devuelve una colección con los valores que contiene el HashMap

    HashMap - Comparación de Objetos

    Para comparar objetos podemos utilizar los métodos equals() y hashCode(), ambos de la interfaz Map:

    • Object1.equals(Object2) - Devuelve cierto si dos objetos son iguales
    • Object1.hashCode() == Object2.hashCode() - Devuelve cierto si ambos objetos tienen el mismo código hash

    Nota importante: Ambos métodos pueden ser utilizados para comparar objetos, pero mediante hashCode() el resultado es más rápido, ya que compara dos números enteros y si es igual querrá decir que estamos frente al mismo objeto.

    Conceptos Clave

    ArrayList

    Estructura que permite almacenar varios datos del mismo tipo. El tamaño de esta estructura es variable en función del número de elementos que contenga en cada momento.

    HashMap

    Colección de objetos que almacena pares clave/valor. Podemos acceder a los elementos del HashMap mediante la clave, ya que éstas tienen un valor único.

    hashCode

    Es un valor numérico entero que sirve para identificar un objeto. En las colecciones de tipo hash tiene especial importancia para identificar objetos iguales de forma rápida.

    Método equals

    Método que compara dos objetos y devuelve un booleano indicando si son iguales o no.
