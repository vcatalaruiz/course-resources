    Acceso a datos con JDBC

    1. Introducción a JDBC

    JDBC (Java Database Connectivity) es una API de Java que permite la conexión y la interacción con bases de datos relacionales. A través de un driver JDBC, se puede establecer conexión con el servidor de BBDD para realizar operaciones SQL como insertar, eliminar, actualizar y consultar datos.

    JDBC actúa como intermediario entre la aplicación Java y el Sistema Gestor de Base de Datos (SGBD), permitiendo ejecutar comandos SQL de forma segura y controlada.

    1.1. Características principales

    • Conexión con bases de datos relacionales (MySQL, PostgreSQL, Oracle, SQL Server, etc.)
    • Ejecución de consultas SQL (SELECT, INSERT, UPDATE, DELETE)
    • Manejo de transacciones y control de errores
    • Consultas parametrizadas para evitar inyecciones SQL
    • Recuperación de resultados mediante ResultSet

    1.2. Flujo de interacción JDBC-SGBD

    2. Objetos JDBC principales

    La gestión de la conexión JDBC implica el uso de varios objetos de diferentes clases para poder gestionar la conexión SQL de forma efectiva.

    2.1. Connection

    Es el objeto que establece y mantiene la conexión con la Base de Datos. Se obtiene a través de DriverManager.getConnection() especificando la URL de conexión, usuario y contraseña. 

    
Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/dam2tp2?serverTimezone=UTC",
    "root",
    "root"
);

    2.2. Statement

    Objeto encargado de ejecutar consultas SQL no parametrizadas directamente. Es más vulnerable a inyecciones SQL y debe evitarse en consultas con parámetros. 

    
Statement stmt = conn.createStatement();
ResultSet rs = stmt.executeQuery("SELECT * FROM Empleados");

    2.3. PreparedStatement

    Objeto encargado de ejecutar consultas SQL parametrizadas. Los caracteres ? se sustituyen por valores reales, proporcionando mayor seguridad contra inyecciones SQL. 

    
String sql = "SELECT * FROM Empleados WHERE id = ? AND edad > ?";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setInt(1, 5);
pstmt.setInt(2, 25);
ResultSet rs = pstmt.executeQuery();

    2.4. ResultSet

    Objeto que contiene los resultados de una consulta SELECT. Se recorre usando un bucle while con el método next() que devuelve true mientras haya registros. 

    
while (rs.next()) {
    int id = rs.getInt("id");
    String nombre = rs.getString("nombre");
    int edad = rs.getInt("edad");
    System.out.println("ID: " + id + ", Nombre: " + nombre + ", Edad: " + edad);
}

    2.5. Tabla resumen de objetos

    Objeto Descripción Uso
    Connection Conexión con la BD Establecer y mantener conexión
    Statement Ejecuta SQL no parametrizado Consultas simples sin parámetros
    PreparedStatement Ejecuta SQL parametrizado Consultas con parámetros (más seguro)
    ResultSet Contiene resultados de consulta Recorrer y acceder a datos

    3. Instalación y configuración del driver JDBC

    3.1. Descarga del driver MySQL

    El driver JDBC de MySQL se descarga desde: https://www.mysql.com/downloads

    • Seleccionar MySQL Community (GPL) Downloads
    • Opción 1: MySQL Installer for Windows (incluye servidor y drivers)
    • Opción 2: MySQL Connector/J (solo el driver JDBC)

    3.2. Uso con Maven

    Si utilizas Maven, añade la dependencia en el archivo pom.xml: 

    
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
    <scope>runtime</scope>
</dependency>

    3.3. Parámetros de conexión

    La URL de conexión tiene la siguiente estructura: 

    
jdbc:mysql://[host]:[puerto]/[schema]?[parámetros]
    Parámetro Descripción Ejemplo
    host Servidor de BD localhost
    puerto Puerto de conexión 3306
    schema Nombre de la BD dam2tp2
    serverTimezone Zona horaria del servidor UTC (o Europe/Madrid)

    Nota importante: El parámetro serverTimezone es determinante para establecer la conexión. Sin él, a veces la conexión puede fallar. Por ejemplo, Madrid es UTC+1.

    4. Autenticación: Usuario y Contraseña

    Debemos especificar las credenciales del usuario que tiene acceso a la base de datos. Estas credenciales están asociadas al servidor MySQL y determinan qué bases de datos y tablas puede acceder el usuario.

    Parámetro Descripción Valor por defecto
    Usuario Nombre de usuario en MySQL root
    Contraseña Contraseña del usuario root

    Con las credenciales correctas, podremos interactuar con todas las tablas y bases de datos que el usuario tenga permisos para acceder.

    5. CRUD con JDBC

    Las operaciones CRUD (Create, Read, Update, Delete) son las cuatro operaciones básicas en cualquier base de datos. A continuación se presentan ejemplos prácticos de cada operación utilizando PreparedStatement para mayor seguridad.

    5.1. Ejemplo: Insertar registros (CREATE)

    La operación CREATE añade nuevos registros a la tabla. Utilizamos executeUpdate() que devuelve el número de filas afectadas. 

    
import java.sql.*;

public class CRUDCreate {
    static final String DB_URL = "jdbc:mysql://localhost/Studra?serverTimezone=UTC";
    static final String USER = "root";
    static final String PASS = "123";

    public static void insertarEmpleado(String nombre, String apellido, int edad, double salario) {
        String sql = "INSERT INTO Empleados (nombre, apellido, edad, salario) VALUES (?, ?, ?, ?)";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            // Reemplaza los parámetros ? con valores reales
            pstmt.setString(1, nombre);
            pstmt.setString(2, apellido);
            pstmt.setInt(3, edad);
            pstmt.setDouble(4, salario);
            
            int filasInsertadas = pstmt.executeUpdate();
            System.out.println("Se insertaron " + filasInsertadas + " registros.");
            
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        insertarEmpleado("Juan", "García", 30, 2500.0);
        insertarEmpleado("María", "López", 28, 2400.0);
        insertarEmpleado("Carlos", "Martínez", 35, 2800.0);
    }
}

    5.2. Ejemplo: Consultar registros (READ)

    La operación READ recupera datos de la tabla. Utilizamos executeQuery() que devuelve un ResultSet con los resultados. 

    
import java.sql.*;

public class CRUDRead {
    static final String DB_URL = "jdbc:mysql://localhost/Studra?serverTimezone=UTC";
    static final String USER = "root";
    static final String PASS = "123";

    // Leer todos los registros
    public static void leerTodos() {
        String sql = "SELECT id, nombre, apellido, edad, salario FROM Empleados";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql);
            ResultSet rs = pstmt.executeQuery()) {

            while (rs.next()) {
                System.out.println("ID: " + rs.getInt("id") + 
                                 ", Nombre: " + rs.getString("nombre") + 
                                 ", Apellido: " + rs.getString("apellido") +
                                 ", Edad: " + rs.getInt("edad") +
                                 ", Salario: " + rs.getDouble("salario"));
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // Leer por criterio (edad mayor que un valor)
    public static void leerPorEdad(int edadMinima) {
        String sql = "SELECT id, nombre, apellido, edad, salario FROM Empleados WHERE edad > ?";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            pstmt.setInt(1, edadMinima);
            
            try(ResultSet rs = pstmt.executeQuery()) {
                while (rs.next()) {
                    System.out.println("ID: " + rs.getInt("id") + 
                                     ", Nombre: " + rs.getString("nombre") + 
                                     ", Edad: " + rs.getInt("edad"));
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        System.out.println("=== Todos los empleados ===");
        leerTodos();
        
        System.out.println("\n=== Empleados con edad > 30 ===");
        leerPorEdad(30);
    }
}

    5.3. Ejemplo: Actualizar registros (UPDATE)

    La operación UPDATE modifica registros existentes. Utilizamos executeUpdate() que devuelve el número de filas modificadas. 

    
import java.sql.*;

public class CRUDUpdate {
    static final String DB_URL = "jdbc:mysql://localhost/Studra?serverTimezone=UTC";
    static final String USER = "root";
    static final String PASS = "123";

    // Actualizar salario por ID
    public static void actualizarSalario(int id, double nuevoSalario) {
        String sql = "UPDATE Empleados SET salario = ? WHERE id = ?";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            pstmt.setDouble(1, nuevoSalario);
            pstmt.setInt(2, id);
            
            int filasActualizadas = pstmt.executeUpdate();
            System.out.println("Se actualizaron " + filasActualizadas + " registros.");
            
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // Actualizar múltiples campos
    public static void actualizarEmpleado(int id, String nombre, String apellido, int edad) {
        String sql = "UPDATE Empleados SET nombre = ?, apellido = ?, edad = ? WHERE id = ?";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            pstmt.setString(1, nombre);
            pstmt.setString(2, apellido);
            pstmt.setInt(3, edad);
            pstmt.setInt(4, id);
            
            int filasActualizadas = pstmt.executeUpdate();
            if (filasActualizadas > 0) {
                System.out.println("Empleado ID " + id + " actualizado correctamente.");
            } else {
                System.out.println("No se encontró empleado con ID " + id);
            }
            
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        actualizarSalario(1, 3000.0);
        actualizarEmpleado(2, "María", "López García", 29);
    }
}

    5.4. Ejemplo: Eliminar registros (DELETE)

    La operación DELETE elimina registros de la tabla. Utilizamos executeUpdate() que devuelve el número de filas eliminadas. 

    
import java.sql.*;

public class CRUDDelete {
    static final String DB_URL = "jdbc:mysql://localhost/Studra?serverTimezone=UTC";
    static final String USER = "root";
    static final String PASS = "123";

    // Eliminar por ID
    public static void eliminarEmpleado(int id) {
        String sql = "DELETE FROM Empleados WHERE id = ?";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            pstmt.setInt(1, id);
            
            int filasEliminadas = pstmt.executeUpdate();
            if (filasEliminadas > 0) {
                System.out.println("Se eliminó 1 empleado.");
            } else {
                System.out.println("No se encontró empleado con ID " + id);
            }
            
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // Eliminar por criterio (empleados con salario menor a un valor)
    public static void eliminarPorSalario(double salarioMaximo) {
        String sql = "DELETE FROM Empleados WHERE salario < ?";
        
        try(Connection conn = DriverManager.getConnection(DB_URL, USER, PASS);
            PreparedStatement pstmt = conn.prepareStatement(sql)) {

            pstmt.setDouble(1, salarioMaximo);
            
            int filasEliminadas = pstmt.executeUpdate();
            System.out.println("Se eliminaron " + filasEliminadas + " empleados con salario < " + salarioMaximo);
            
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    public static void main(String[] args) {
        eliminarEmpleado(3);
        eliminarPorSalario(2300.0);
    }
}

    5.5. Tabla comparativa de métodos

    Operación Comando SQL Método Retorna
    CREATE INSERT executeUpdate() int (filas insertadas)
    READ SELECT executeQuery() ResultSet
    UPDATE UPDATE executeUpdate() int (filas modificadas)
    DELETE DELETE executeUpdate() int (filas eliminadas)
