¿Qué es un Servidor Web y por qué protegerlo?

01 / 08

Un servidor web es un software esencial que actúa como intermediario entre los usuarios (navegadores) y las aplicaciones web, procesando peticiones HTTP/HTTPS[cite: 5].

🏠 Analogía Didáctica Visual

Los servidores web son como la puerta principal de una casa: por ahí entra todo el mundo[cite: 8]. Su alta accesibilidad los convierte en el blanco principal de los ciberdelincuentes.

Seguridad en Aplicaciones

Principales Amenazas de Seguridad

02 / 08
XSS (Cross-Site Scripting)

Inyección de scripts maliciosos ejecutados en el navegador del usuario (Reflejado, Almacenado y DOM)[cite: 9].

Impacto: Robo de sesiones
Inyección SQL (SQLi)

Manipulación de consultas a bases de datos para extraer, modificar o borrar registros sensibles[cite: 10].

Impacto: Exfiltración de datos
Ataques DoS / DDoS

Sobrecarga masiva de solicitudes o ancho de banda para agotar los recursos de CPU y memoria del servidor[cite: 12].

Impacto: Caída del servicio

ModSecurity: Firewall de Aplicaciones Web (WAF)

04 / 08

ModSecurity es un WAF de código abierto que analiza, filtra y bloquea solicitudes HTTP/HTTPS maliciosas antes de que lleguen a la aplicación web[cite: 22].

Ejemplo de Regla WAF Personalizada:

SecRule REQUEST_URI "@contains /admin" "id:1234, deny, status:403, msg:'Acceso no autorizado'"[cite: 27]
Despliegue rápido en Linux:

sudo apt install libapache2-mod-security2[cite: 25]

# Activar módulo y reglas OWASP CRS

sudo a2enmod security2
git clone https://github.com/coreruleset/coreruleset /usr/share/modsecurity-crs[cite: 25, 26]

Nginx: Configuración y Mitigación

05 / 08

Directivas Clave (nginx.conf)

# Ocultar versión del servidor

server_tokens off;[cite: 29]

# Bloquear ficheros ocultos (.git, .env)

location ~ /\. { deny all; }[cite: 30]

# Limitar métodos HTTP permitidos

if ($request_method !~ ^(GET|POST|HEAD)$) { return 405; }[cite: 35]

Mitigación Anti-DDoS (Rate Limiting)

# Limitar peticiones a 10 req/s por IP

limit_req_zone $binary_remote_addr zone=one:10m rate=10r/s;

server {
  location / {
    limit_req zone=one burst=5;
  }
}[cite: 33]

Entornos Empresariales Windows

Internet Information Services (IIS)

06 / 08

Mejoras de Seguridad en IIS

  • ✔️ Protocolos Seguros: Deshabilitar SSL 2.0/3.0 y TLS 1.0, manteniendo solo TLS 1.2+[cite: 41].
  • ✔️ Dynamic IP Restrictions: Mitigar fuerza bruta y ataques DoS limitando IPs sospechosas[cite: 42].
  • ✔️ Cabeceras HTTP: HSTS, X-Frame-Options y X-Content-Type-Options configuradas nativamente[cite: 42].

Herramientas Oficiales

IIS Crypto: Utilidad gráfica para aplicar perfiles de cifrado seguros acordes a normativas PCI DSS, HIPAA o NIST[cite: 45].

Security Compliance Toolkit: Plantillas avanzadas de políticas de seguridad predefinidas por Microsoft[cite: 46].
