UT 2. Programación de eventos y construcción de aplicaciones visuales

1. Introducción al modelo de eventos en desarrollo web

1.1. Concepto de evento y manejadores en JavaScript

Un evento es cualquier acción que ocurre en la página web y que puede ser detectada mediante JavaScript, permitiendo que la aplicación responda de manera interactiva. Los elementos que intervienen en un evento son:

  • Elemento: nodo HTML que genera el evento (por ejemplo, <button>, <input>, <form>).
  • Evento: tipo de acción que ocurre (por ejemplo, click, input, submit).
  • Manejador: función JavaScript que se ejecuta cuando ocurre el evento.

Tipos de eventos frecuentes:

  • Mouse: click, dblclick, mouseover, mouseout, mousemove.
  • Teclado: keydown, keyup.
  • Formulario: input, change, submit, focus, blur.
  • Ventana/documento: load, resize, scroll, DOMContentLoaded.

Ejemplo práctico de manejador:

document.getElementById("miBoton").addEventListener("click", function() {
    alert("Botón clicado!");
});

1.2. Ciclo de vida de una aplicación web basada en eventos

Las etapas principales del ciclo de vida de una aplicación web basada en eventos son:

  1. Carga del DOM y ejecución de scripts.
  2. Asignación de eventos y espera activa del usuario.
  3. Propagación de eventos: bubbling y capturing.
  4. Ejecución de manejadores y actualización del DOM.
  5. Repetición del ciclo hasta cierre de página o navegación.

Ejemplo:

document.addEventListener("DOMContentLoaded", function() {
    console.log("DOM completamente cargado y analizado");
});

2. Asociación de acciones a eventos en páginas web

2.1. Captura de eventos del usuario en el DOM

La delegación de eventos permite manejar eventos de varios elementos hijos desde un contenedor. Ejemplo:

document.getElementById("miLista").addEventListener("click", function(event) {
    if (event.target.tagName === "LI") {
        alert("Elemento de lista clicado: " + event.target.textContent);
    }
});

2.2. Métodos para asignar funciones a eventos

Se pueden usar atributos HTML, propiedades de objeto, y el método addEventListener. Ejemplo:

<button onclick="miFuncion()">Click</button>
<script>
    function miFuncion() {
        alert("Botón clicado!");
    }
</script>

3.1. Integración de estructura HTML, estilos CSS y lógica JavaScript

Vamos a desglosar y explicar los puntos más relevantes del código proporcionado para el desarrollo de una aplicación web completa:

Lógica JavaScript

Vamos a explicar cada parte del JavaScript y su vinculación con el HTML:

document.getElementById('registroForm').addEventListener('submit', function(e) {
    e.preventDefault();
    let valido = true;
    const nombre = document.getElementById('nombre');
    const email = document.getElementById('email');
    const password = document.getElementById('password');
    const acepto = document.getElementById('acepto');
    document.getElementById('errorNombre').textContent = '';
    document.getElementById('errorEmail').textContent = '';
    document.getElementById('errorPassword').textContent = '';
    document.getElementById('errorAcepto').textContent = '';
    document.getElementById('resultado').textContent = '';
    if (nombre.value.trim() === '') {
        document.getElementById('errorNombre').textContent = 'Nombre obligatorio';
        valido = false;
    }
    if (email.value.trim() === '') {
        document.getElementById('errorEmail').textContent = 'Correo obligatorio';
        valido = false;
    }
    if (password.value.length < 6) {
        document.getElementById('errorPassword').textContent = 'Contraseña mínima 6 caracteres';
        valido = false;
    }
    if (!acepto.checked) {
        document.getElementById('errorAcepto').textContent = 'Debe aceptar términos';
        valido = false;
    }
    if (valido) {
        document.getElementById('resultado').textContent = 'Registro exitoso';
        this.reset();
    }
});

Explicación:

  • Captura del evento submit: Se añade un manejador de eventos al formulario para capturar el evento submit y evitar el comportamiento por defecto (recargar la página) usando e.preventDefault().
  • Validación de campos: Se obtienen los valores de los campos de entrada y se comprueba si están vacíos o no cumplen con los requisitos. Si hay errores, se muestran mensajes de error específicos.
  • Mostrar mensajes de éxito: Si todos los campos son válidos, se muestra un mensaje de éxito y se reinicia el formulario.
